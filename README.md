# 🚀 ربات هوشمند فروش اشتراک VIP (پیام‌رسان بله)

این پروژه یک ربات هوشمند و بسیار سبک برای پیام‌رسان بله است که جهت فروش، کنترل و مدیریت اشتراک‌های ویژه (VIP) طراحی شده است. تمامی امکانات مدیریت و فروش در داخل خود ربات (از طریق دستور `/admin`) انجام می‌شود و نیازی به کنترل پنل تحت وب، دیتابیس‌های پیچیده و سرورهای سنگین ندارد.

## ✨ امکانات برجسته
* **پنل مدیریت درون ربات:** تمامی کارها (افزودن پلن، حذف پلن، تایید فیش، تخصیص اشتراک و...) مستقیماً در خود پیام‌رسان بله انجام می‌شود.
* **سبک و فوق‌سریع:** عدم استفاده از دیتابیس‌های سنگین. تمامی اطلاعات در یک فایل `db.json` محلی ذخیره می‌شود که باعث می‌شود روی ضعیف‌ترین سرورها نیز با سرعت بالا و بدون افت کیفیت اجرا شود.
* **مدیریت پلن‌های اشتراکی:** امکان تعریف بی‌نهایت طرح (مثلاً ۱ ماهه، ۳ ماهه و...) با قیمت و توضیحات برای هر کدام.
* **تولید شناسه یکتای اشتراک:** تولید خودکار شناسه اختصاصی (مانند `SUB_5432`) برای هر اشتراک جهت ایجاد اتصال راحت‌تر با پنل‌های مدیریت VPN.
* **سیستم پرداخت کارت‌به‌کارت:** دریافت عکس رسید از کاربر، ارسال آن به ادمین جهت تایید/رد، تولید شناسه یکتا پیش از تایید نهایی و در نهایت ارسال لینک.
* **ارسال پیام همگانی (Broadcast):** قابلیت ارسال مستقیم پیام به تمامی کاربران ربات مستقیماً از بخش مدیریت.
* **جستجوی کاربر:** امکان مشاهده مشخصات کامل و وضعیت اشتراک‌های فعال هر کاربر به سادگی از طریق آیدی بله یا نام کاربری.

## 🛠 تکنولوژی‌های استفاده شده
* **زبان و محیط اجرا:** TypeScript, Node.js
* **ذخیره‌سازی اطلاعات:** Local JSON Database (`db.json`)
* **باندلر:** esbuild (جهت بیلد یکپارچه، سریع و با حجم پایین)

## 🚀 آموزش نصب کاملاً خودکار (مخصوص سرور لینوکس)

برای نصب این پروژه روی سرور مجازی (VPS) نیازی به دانش فنی خاصی ندارید. ما یک اسکریپت نصب کاملا خودکار برای شما آماده کرده‌ایم.

۱. ابتدا سورس‌کد را روی سرور خود دانلود کنید:
```bash
git clone https://github.com/hamidesmaildoc-ai/eshterak-bale.git
cd eshterak-bale
```

۲. فایل نصب خودکار را با دسترسی روت اجرا کنید:
```bash
sudo bash install.sh
```

۳. در حین نصب، اسکریپت از شما دو سوال ساده می‌پرسد:
* **توکن ربات بله:** (توکنی که از `botfather` بله دریافت کرده‌اید)
* **آیدی عددی مدیریت:** (آیدی عددی شما در پیام‌رسان بله برای دسترسی به دستور `/admin` و دریافت فیش‌های واریزی)

> **توجه:** اسکریپت به صورت خودکار پکیج‌های لازم، Node.js و ابزار قدرتمند PM2 را نصب کرده و ربات شما را پس از اجرای موفق، برای همیشه روشن نگه می‌دارد (حتی بعد از ری‌استارت شدن سرور).

## 💻 راه‌اندازی دستی (برای توسعه‌دهندگان)

اگر قصد دارید تغییراتی در کدها بدهید یا به صورت دستی پروژه را اجرا کنید:

۱. نصب وابستگی‌ها:
```bash
npm install
```

۲. تنظیم متغیرهای محیطی:
فایل `.env.example` را به `.env` تغییر نام داده و مقادیر زیر را در آن پر کنید:
```env
BALE_BOT_TOKEN="توکن ربات شما"
ADMIN_CHAT_ID="آیدی عددی شما"
```

۳. اجرای نسخه توسعه‌دهنده:
```bash
npm run dev
```

۴. ساخت نسخه نهایی و اجرای آن در بک‌گراند:
```bash
npm run build
pm2 start dist/server.cjs --name "bale-bot"
pm2 save
```
