# 🚀 پنل مدیریت و ربات فروش اشتراک VIP (پیام‌رسان بله)

این پروژه یک سیستم کامل (شامل ربات هوشمند برای پیام‌رسان بله و یک پنل مدیریت تحت وب) جهت فروش، کنترل و مدیریت اشتراک‌های ویژه (VIP) است. با استفاده از این سورس‌کد می‌توانید به راحتی کانال‌ها و گروه‌های پولی (VIP) خود را در بله اتوماتیک کنید و از طریق سیستم کارت‌به‌کارت درآمد کسب کنید.

## ✨ امکانات برجسته

* **پنل مدیریت تحت وب:** رابط کاربری زیبا، مدرن و واکنش‌گرا (Responsive) برای مدیریت کل سیستم.
* **مدیریت پلن‌های اشتراکی:** امکان تعریف بی‌نهایت طرح (مثلاً ۱ ماهه، ۳ ماهه و...) با قیمت، توضیحات و لینک‌های عضویت اختصاصی برای هر کدام.
* **سیستم پرداخت کارت‌به‌کارت:** دریافت خودکار رسید بانکی یا شماره پیگیری از کاربر و تایید/رد آن توسط ادمین در ربات.
* **مدیریت کاربران:** مشاهده لیست کامل کاربران، وضعیت اشتراک آن‌ها (فعال/منقضی) و قابلیت مدیریت دستی اشتراک‌ها از طریق پنل.
* **ارسال پیام همگانی (Broadcast):** ارسال پیام متنی به تمامی اعضای ربات به صورت یکجا و مستقیم از پنل مدیریت.
* **ارسال پیام تکی:** قابلیت ارسال مستقیم پیام به یک کاربر خاص از طریق پنل.
* **دیتابیس قدرتمند:** استفاده از پایگاه داده PostgreSQL برای ذخیره‌سازی امن، سریع و پایدار داده‌ها.

## 🛠 تکنولوژی‌های استفاده شده

* **فرانت‌اند (Frontend):** React.js, Tailwind CSS, Vite, Lucide Icons
* **بک‌اند (Backend):** Node.js, Express.js, TypeScript
* **دیتابیس (Database):** PostgreSQL, Drizzle ORM
* **ارتباط با پیام‌رسان:** Bale Bot API

## 🚀 آموزش نصب کاملاً خودکار (مخصوص سرور اوبونتو)

برای نصب این پروژه روی سرور مجازی (VPS) با سیستم‌عامل Ubuntu، نیازی به دانش فنی برنامه‌نویسی و لینوکس ندارید. ما یک اسکریپت نصب خودکار در پروژه قرار داده‌ایم که صفر تا صد راه‌اندازی را خودش انجام می‌دهد!

۱. ابتدا سورس‌کد را روی سرور خود دانلود کنید (یا از طریق گیت کلون کنید):
```bash
git clone https://github.com/hamidesmaildoc-ai/eshterak-bale.git
cd eshterak-bale
```

۲. فایل نصب خودکار را با دسترسی روت (Root) اجرا کنید:
```bash
sudo bash install.sh
```

۳. در حین نصب، اسکریپت از شما دو سوال می‌پرسد:
* **توکن ربات بله:** (از بازو بات‌فادر بله بگیرید)
* **آیدی عددی بله ادمین:** (آیدی بله خودتان تا فیش‌های واریزی برای شما ارسال شود)

> **توجه:** اسکریپت به صورت خودکار Node.js، دیتابیس PostgreSQL و PM2 را نصب کرده، دیتابیس را کانفیگ می‌کند و پروژه را روی سرور شما برای همیشه روشن نگه می‌دارد.

🌐 **دسترسی به پنل:** پس از پایان نصب، می‌توانید از طریق مرورگر به آدرس `http://YOUR_SERVER_IP:3000` مراجعه کنید.

## ⚙️ نصب دستی (برای توسعه‌دهندگان)

اگر برنامه‌نویس هستید و می‌خواهید پروژه را روی لوکال (کامپیوتر شخصی) یا سرویس‌های ابری شخصی‌سازی کنید:

۱. نصب وابستگی‌ها:
```bash
npm install
```

۲. دیتابیس:
یک دیتابیس PostgreSQL بسازید (یا از سرویس‌هایی مثل Supabase/Neon استفاده کنید).

۳. متغیرهای محیطی:
فایل `.env.example` را به `.env` تغییر نام دهید و اطلاعات اتصال دیتابیس و توکن ربات خود را وارد کنید.

۴. اعمال ساختار دیتابیس (Migration):
```bash
npx drizzle-kit push --config=src/db/drizzle.config.ts
```

۵. اجرای پروژه در حالت توسعه:
```bash
npm run dev
```

## 🌍 اتصال دامنه و فعال‌سازی SSL (HTTPS)

برای اینکه پنل مدیریت خود را روی یک دامنه اختصاصی (مثلاً `panel.yourdomain.com`) بالا بیاورید و همچنین قفل سبز رنگ (SSL) را برای امنیت فعال کنید، ما یک اسکریپت جادویی دیگر برای شما آماده کرده‌ایم!

۱. ابتدا وارد پنل دامنه خود شوید (یا Cloudflare) و یک رکورد `A` به IP سرور خود متصل کنید.
۲. صبر کنید تا DNS دامنه شما فعال شود (معمولاً چند دقیقه تا چند ساعت طول می‌کشد).
۳. سپس این دستور را در سرور خود وارد کنید:
```bash
sudo bash setup-domain.sh
```

این اسکریپت به صورت خودکار:
* وب‌سرور قدرتمند `Nginx` را نصب می‌کند.
* ابزار `Certbot` را نصب করে گواهینامه SSL رایگان (`Let's Encrypt`) برای دامنه شما دریافت می‌کند.
* تنظیمات `Reverse Proxy` را انجام می‌دهد تا درخواست‌های دامنه به صورت امن به ربات شما در پورت 3000 متصل شوند.
* ترافیک کاربر را به صورت خودکار به `https://` هدایت (Redirect) می‌کند.
